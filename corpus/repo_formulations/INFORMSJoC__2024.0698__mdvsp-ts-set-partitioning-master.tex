%@ name :: mdvsp-ts-set-partitioning-master
%@ desc :: Extended set-partitioning (route-based / Dantzig-Wolfe) reformulation of the MDVSP-TS solved by branch-and-price. A column is a feasible vehicle route (an ordered sequence of trips for one depot) with a precomputed cost; the master selects a minimum-cost set of routes covering each trip exactly once. Columns are generated by a per-depot resource-constrained shortest-path pricing problem over a connection network, where the time-shifting window (maxDeviation) is the resource handled in the label start-time. Branching is done on color (depot assignment), inter-task arcs, and most-fractional arcs. The master LP relaxation is what is actually solved at each B&P node.
