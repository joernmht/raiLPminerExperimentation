%@ name :: crew-pairing-set-covering-master
%@ desc :: Set-covering / set-partitioning master problem of a column-generation crew-pairing scheduler for an airline. Each candidate column is a crew roster (an ordered sequence of duties: execution flights, positioning flights/buses, ground duties) generated by the pricing subproblem. The master selects at most one roster per crew so that every flight and every mandatory ground duty is covered, otherwise an explicit uncovered-slack variable is penalized. Solved as an LP relaxation each column-generation iteration to obtain duals (solve_lp), and finally as a binary integer program (solve_bip). Built incrementally: constraints are created empty at setup and re-formed as columns are added in _add_roster.
%@ prov source :: https://github.com/Yinwenxu-1212/crewScheduling
%@ prov author :: Yinwenxu-1212/crewScheduling
%@ index K ordered=0 cyclic=0 :: set of crews
%@ index F ordered=0 cyclic=0 :: set of (execution) flights to be covered
%@ index G ordered=0 cyclic=0 :: set of mandatory ground duties (occupancy tasks) to be covered
%@ index R ordered=0 cyclic=0 :: set of generated rosters (columns); each roster r belongs to one crew
%@ index R_k ordered=0 cyclic=0 :: rosters belonging to crew k
%@ index R_f ordered=0 cyclic=0 :: rosters that cover flight f by executing it (non-positioning)
%@ index R_g ordered=0 cyclic=0 :: rosters that cover ground duty g
%@ param c shape=R kind=vector domain=- :: cost of roster r = positioning_penalty + overnight_penalty + violation_penalty - flight_reward; flight_reward = FLIGHT_TIME_REWARD * roster_flight_hours / global_duty_days_denominator (global average daily flight-time approximation) [domain R]
%@ param P_F shape=- kind=scalar domain=- :: penalty per uncovered flight (UNCOVERED_FLIGHT_PENALTY) [domain R_>=0]
%@ param P_G shape=- kind=scalar domain=- :: penalty per uncovered ground duty (UNCOVERED_GROUND_DUTY_PENALTY) [domain R_>=0]
%@ param a shape=R,F kind=matrix domain=- :: 1 if roster r executes (non-positioning) flight f, else 0; encoded implicitly via membership of v in flight f's covering_vars [domain {0,1}]
%@ param b shape=R,G kind=matrix domain=- :: 1 if roster r covers ground duty g, else 0; encoded implicitly via membership of v in ground duty g's covering_vars [domain {0,1}]
%@ var x shape=R domain=binary role=primary drole=- lo=- hi=- :: 1 if roster r is selected (LP-relaxed to [0,1] in solve_lp; lb=0.1 protective lower bound for initial-solution columns)
%@ var u shape=F domain=binary role=primary drole=- lo=- hi=- :: 1 if flight f is left uncovered (slack), in [0,1]
%@ var z shape=G domain=binary role=primary drole=- lo=- hi=- :: 1 if ground duty g is left uncovered (slack), in [0,1]
%@ obj sense=min name=objective combination=sum :: minimize total selected-roster cost plus penalties for uncovered flights and uncovered ground duties (objective coefficients set directly via the obj= argument on each addVar; ModelSense = MINIMIZE)
%@ con crew_at_most_one_roster kind=linear domain=- indicator=- :: each crew is assigned at most one roster (created empty at setup, rebuilt as columns are added)
%@ con flight_cover kind=linear domain=- indicator=- :: each flight is executed by exactly one selected roster, or counted as uncovered (set-partitioning equality with slack; initialized as u_f = 1)
%@ con ground_duty_cover kind=linear domain=- indicator=- :: each mandatory ground duty is covered by exactly one selected roster, or counted as uncovered (set-partitioning equality with slack; initialized as z_g = 1)
\begin{align}
  \min\quad & \sum_{r \in \mathcal{R}} c \cdot x_{r} + \sum_{f \in \mathcal{F}} \mathit{P\_F} \cdot u_{f} + \sum_{g \in \mathcal{G}} \mathit{P\_G} \cdot z_{g} \tag{objective} \\
  & \sum_{r \in \mathcal{R_k}} x_{r} \le 1 \qquad \forall k \in \mathcal{K} \tag{crew\_at\_most\_one\_roster} \\
  & \sum_{r \in \mathcal{R_f}} x_{r} + u_{f} = 1 \qquad \forall f \in \mathcal{F} \tag{flight\_cover} \\
  & \sum_{r \in \mathcal{R_g}} x_{r} + z_{g} = 1 \qquad \forall g \in \mathcal{G} \tag{ground\_duty\_cover} \\
\end{align}
