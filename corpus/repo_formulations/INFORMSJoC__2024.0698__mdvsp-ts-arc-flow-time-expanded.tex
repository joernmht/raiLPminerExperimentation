%@ name :: mdvsp-ts-arc-flow-time-expanded
%@ desc :: Arc-flow (multi-commodity, one commodity per depot) formulation of the Multi-Depot Vehicle Scheduling Problem with Trip Shifting on a fully time-expanded network. Each depot has its own copy of the time-space graph; integer arc-flow variables route vehicles from a source depot node to a sink depot node. Trip shifting is modelled implicitly: each timetabled trip is expanded into multiple parallel trip arcs, one per admissible departure-time deviation in [-maxDeviation, +maxDeviation] (TimeSpaceGraph.initNodes/addTripArcs), and a cover constraint forces exactly one of these copies (across all depots) to be used. Objective minimizes total cost = fixed cost per vehicle (pull-in/pull-out arcs) + variable deadheading cost. This is the model solved both by the MIP baseline (SolverMIP on the full network) and, on iteratively refined sparser networks, by the DDD algorithm; the formulation is identical, only the underlying TimeSpaceGraph differs.
